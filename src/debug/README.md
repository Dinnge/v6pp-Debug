# V6++ 调试器模块

## 概述

这是一个为 V6++ 内核开发的调试器模块,支持 GDB 远程协议。

## 目录结构

- `debug.h` - 调试器主头文件
- `gdb/` - GDB 协议实现
  - `debugger.cpp` - 调试器集成接口
  - `gdb_protocol.h` - GDB 协议头文件
  - `gdb_protocol.cpp` - GDB 协议实现
- `boot/` - 启动调试支持(待实现)
- `fs/` - 文件系统调试支持(待实现)
- `json/` - JSON 调试数据支持(待实现)

## GDB 远程协议

### 支持的命令

- `c` - 继续执行
- `s` - 单步执行
- `g` - 读取所有寄存器
- `G` - 写入所有寄存器
- `m` - 读取内存
- `M` - 写入内存
- `Z` - 设置断点
- `z` - 移除断点
- `q` - 查询命令

## 使用方法

### 编译

```bash
cd build
cmake ..
make
```

### 连接 GDB

```bash
gdb your-kernel-image
(gdb) target remote :1234
```

### 示例

```bash
# 设置断点
(gdb) break main

# 继续执行
(gdb) continue

# 单步执行
(gdb) step

# 查看寄存器
(gdb) info registers

# 查看内存
(gdb) x/10x 0x1000
```
